### 🚀 Background & Focus

I specialize in **Network Engineering, Infrastructure, and Cross-Platform Application Development**, bridging the gap between low-level hardware communication and modern mobile software.

- 🌐 **Networks & Systems:** Enterprise routing/switching (Cisco topologies, OSPF, VLANs, ACLs), Linux environments, VPNs (Tailscale), and self-hosted infrastructure.
- 📱 **Mobile Engineering:** Building cross-platform applications with **Flutter & Dart**, focusing on clean state architecture and offline-first data pipelines.
- 🤖 **Embedded & Hardware:** Developing smart robotics, IoT nodes, and serial telemetry via **Arduino & Raspberry Pi**.
- 🛠️ **Automation & Data:** Network analysis, automation scripting, and ML data parsing using **Python**.
